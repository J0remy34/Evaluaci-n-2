## Descripción

Proyecto desarrollado para la Evaluación Sumativa 2 de la asignatura de Back End.

El proyecto utiliza Django para desarrollar un sitio web con dos temas,
templates, archivos estáticos y componentes de Bootstrap.

## Tecnologías utilizadas

- Python
- Django
- HTML
- CSS
- Bootstrap
- Git
- GitHub

## Funcionalidades

- Página de inicio.
- Listado de dos temas.
- Cards de Bootstrap.
- Vista individual para cada tema.
- Carousel de imágenes.
- Archivos estáticos.
- Navegación mediante URLs.
- Templates heredados desde `base.html`.

## Estructura

El proyecto está organizado utilizando una aplicación Django,
templates y archivos estáticos separados por carpetas.
